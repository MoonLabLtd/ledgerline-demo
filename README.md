# Ledgerline

Local-first, single-user sales dashboard. Record sales, products and customers on your own machine and see revenue,
trends, rankings and insights. Next.js 16 (App Router) on SQLite.

The app is built from the Ledgerline specification in
[MoonLabLtd/sales-dashboard-app](https://github.com/MoonLabLtd/sales-dashboard-app). This README is replaced by the
user guide when the app is complete.
